# Static assets

Brand artwork here comes from the chapter's own WordPress theme
(`dsa_wordpress_theme`) on the live `siliconvalleydsa.org`, used with the
chapter's authorization — the same footing as the brand font, whose note is in
`public/fonts/README.md`.

| File                | What it is                                                                             | Where it came from                                          |
| ------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `dsa-rose-mark.svg` | The DSA rose mark, red. The top bar's brand mark.                                      | `…/dsa_wordpress_theme/assets/images/dsa-rose-mark-red.svg` |
| `svdsa-logo.svg`    | The chapter's circuit-tree-and-handshake emblem. Fills the left half of the hero band. | The same theme's `svdsa-logo` background image              |
| `solidarity.svg`    | Hands illustration, from the `red` theme's hero. Unused by `theme/faithful`.           | Drawn for this rebuild                                      |

`favicon-*.png` and `apple-touch-icon.png` are the site icons; `media/` holds
images the WordPress migration brought across with the pages that reference
them.

When this moves onto official DSA infrastructure, confirm the rose mark sits
under DSA's own brand arrangement there (nothing to change technically).
